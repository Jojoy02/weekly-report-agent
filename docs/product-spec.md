# Product Spec

## Problem
跨团队周报存在信息结构、关注重点和表达口径差异。人工需要反复阅读来源材料、识别相关事项、关联历史状态并重新组织目标团队内容。

## Product Goal
将非确定性的 LLM 文本转化任务设计成：可控、可降级、可评测、可追踪、可持续迭代。

## Core Modules
1. Target Reader
2. Source Parser
3. Context Builder
4. Reference Loader
5. Transformation Engine
6. Validator
7. Human Review
8. Commit Gate
9. Read-back Checker
10. Rule Governance
